✦ iOS / iPhone Installation

  1. Tap the Share button (box with an arrow) in Safari.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add in the top-right corner to install Fausti Arts.

This application is also built as a native Android APK and App Bundle. You can download the installable APK directly or export the production package from the AI Studio menu.
